# Базовый контракт проекта «Поток»

> **Назначение:** Контракт проекта `aoanima.ru/potok` — T9-предиктор слов для Windows
> с автопереключением раскладки RU/EN на 4-кнопочной клавиатуре.
> Наследует универсальный шаблон `Templates/base-contract.md` (уровень 0).
>
> **Важно:** Шаблон `Templates/` не менять. Этот файл — точка входа в систему
> контрактов проекта.

---

## 1. Метаданные проекта

```yaml
проект:
  название: "Поток"
  описание: "T9-предиктор слов для Windows: перехват нажатий клавиш (low-level hook), построение буфера виртуальных кодов, предсказание слова по Trie + n-граммной модели (HMM/Viterbi) с автопереключением раскладки RU/EN, вставка предсказания через SendInput, отображение подсказок в окне (windigo)."
  версия: "0.1.0"
  дата_создания: "2025-01-27"
  дата_обновления: "2026-07-13"

стек:
  язык: "Go 1.23.4"
  фреймворк: "net (стандартная библиотека) + github.com/rodrigocfd/windigo (Win32 UI)"
  база_данных: "none (локальные JSON/текстовые файлы данных)"
  шаблонизатор: "none (UI — нативный Win32 через windigo, не HTML)"
  логирование: "aoanima.ru/Logger (dot-import: . \"aoanima.ru/Logger\")"
  дополнительные_зависимости:
    - "aoanima.ru/Logger        (replace ../Logger)"
    - "aoanima.ru/QErrors       (replace ../QErrors)"
    - "aoanima.ru/Utilites      (replace ../Utilites)"
    - "github.com/rodrigocfd/windigo   (Win32 GUI)"
    - "github.com/gookit/color"
    - "github.com/xo/terminfo"
    - "golang.org/x/sys"

репозиторий:
  url: "https://github.com/AoAnima/potok"
  ветка_по_умолчанию: "main"
```

> **Платформа:** Windows-only. Используются `user32.dll`, `gdi32.dll`, `Kernel32.dll`
> через `syscall.NewLazyDLL`/`syscall.SyscallN` и библиотека `windigo`. Сборка и
> запуск — только на Windows.

## 2. Методология

| Методология | Описание | Применение |
|-------------|----------|------------|
| **SDD** — Specification-Driven Development | Разработка через спецификации | Компоненты описываются спецификациями до кода |
| **ACDD** — Acceptance Criteria-Driven Development | Критерии приёмки для каждого компонента | Каждый контракт содержит критерии приёмки |
| **Output Contract** | Спецификация выходных данных | Формат предсказаний и вставляемого текста |
| **Inheritable Contracts** | Контракты наследуют друг друга | Templates → base-contract → специфичные |

## 3. Система наследования контрактов

```
Уровень 0: Templates/base-contract.md          ← универсальный шаблон (НЕ менять)
Уровень 2: контракты проекта Поток/
   ├── base-contract.md        ← копия уровня 0 с заполненными плейсхолдерами
   ├── code-style.md           ← стиль (наследует + проектные отклонения)
   ├── data-contract.md        ← локальные данные (наследует base) [*]
   ├── api-contract.md         ← интерфейс хука/предсказания (наследует base) [*]
   └── README.md               ← индекс контрактов
```

### Правила наследования

```yaml
inheritance_rules:
  rule_1: "Никогда не изменяйте Templates/base-contract.md"
  rule_2: "Каждый контракт наследует методологию и принципы базового"
  rule_3: "Дочерний контракт может переопределять (override) секции родителя"
  rule_4: "При переопределении указывайте: # override: base-contract.md → секция"
  rule_5: "Каждый контракт содержит критерии приёмки (AC)"
```

```yaml
# override: base-contract.md → 1. стек.база_данных
база_данных: "none (локальные файлы данных, не СУБД)"

# override: base-contract.md → 4. структура (нет role-contract / template-contract)
отсутствующие_контракты:
  причина_role: "Нет авторизации/RBAC — приложение локальное, без пользователей и прав"
  причина_template: "Нет веб-UI и шаблонизатора — интерфейс нативный Win32 (windigo)"
```

## 6. Архитектура системы

```
┌──────────────────────────────────────────────────────────────┐
│  Системный хук (SetWindowsHookEx)                             │
│  WH_KEYBOARD_LL ──▶ ХукКлавиатуры (callback)                  │
│  WH_MOUSE_LL   ──▶ ХукМыши (callback)                         │
└───────────────────────────┬──────────────────────────────────┘
                            │ VK-коды (ВиртуальныйКод)
                            ▼
┌──────────────────────────────────────────────────────────────┐
│  БуферНажатий  ──▶ ПредсказаниеСлов (goroutine)               │
│     │                                                      │
│     │ Trie (деревоСлов.go)                                 │
│     │ МодельNграмм / HMM (статистика.go)                   │
│     │ Гибрид + Viterbi-декодирование                       │
│     └──────────────▶ каналПредсказания (chan)              │
└───────────────────────────┬──────────────────────────────────┘
                            ▼
┌──────────────────────────────────────────────────────────────┐
│  ПотокОбновленияЮИ (goroutine)                                │
│     │ каналОбновленияОкна (chan)                              │
│     ▼                                                         │
│  windigo: ГлавноеОкно + ОкноПодсказок                         │
│     │                                                         │
│     ▼ SendInput (user32) ──▶ вставка предсказанного слова     │
└──────────────────────────────────────────────────────────────┘

Данные (локальные файлы, data/):
  dictionaries/ ── словари RU/EN
  frequency_cache.json ── частотный кэш
  ngrams.json ── n-граммная модель
  layout.json ── раскладка 4-кнопочной клавиатуры (Алфавит)
  user_words.txt ── пользовательский словарь
```

```yaml
компоненты:
  - название: "ХукКлавиатуры"
    технология: "user32 SetWindowsHookEx WH_KEYBOARD_LL"
    протокол: "Win32 callback"
  - название: "ПредсказаниеСлов"
    технология: "Trie + МодельNграмм + Viterbi"
```
