# Контракт данных проекта «Поток»

> Наследует: `base-contract.md` (уровень 2)
> Переопределяет: `base-contract.md` §1 (стек.база_данных → none, локальные файлы)
>
> Проект **не использует СУБД**. Все данные — локальные файлы в каталоге `data/`
> (и `bin/`). Форматы: JSON (раскладка, кэш, n-граммы) и текстовые списки слов.

---

## 1. Обзор хранилища

```yaml
хранилище:
  тип: "локальные файлы (filesystem)"
  субд: "none"
  кэш_в_памяти: "Трие (деревоСлов.go), МодельNграмм (статистика.go)"
  сериализация: "encoding/json (стандартная библиотека Go)"
```

| Файл | Назначение | Формат | Загрузчик |
|------|-----------|--------|-----------|
| `data/layout.json` | Раскладки 4-кнопочной клавиатуры + макросы | JSON | `поток.go` |
| `data/frequency_cache.json` | Частотный кэш слов (слово→частота) | JSON `map[string]int` | `поток.go` |
| `data/ngrams.json` | N-граммная модель (HMM) | JSON (МодельNграмм) | `статистика.go` |
| `data/dictionaries/russian_words.txt` | Русский словарь (база Trie) | текст, слово/строка | `деревоСлов.go` |
| `data/dictionaries/english_words.txt` | Английский словарь (база Trie) | текст, слово/строка | `деревоСлов.go` |
| `data/dictionaries/Щдв_russian_words.txt` | Вариант русского словаря | текст | (опционально) |
| `data/user_words.txt` | Пользовательский словарь (добавленные слова) | текст | `деревоСлов.go` |
| `bin/config.json` | ⚠️ мёртвая конфигурация (ссылка на jetHTML) | JSON | не используется |

## 2. Схемы данных

### 2.1. `data/layout.json`

```json
{
  "activeLayout": "СвернутаяQWER",
  "layouts": [
    {
      "name": "СвернутаяQWER",
      "algorithm": 2,
      "keys": [
        [
          {"vk": 27, "label": "ESC", "ru": ["ESC"], "en": ["ESC"]},
          {"vk": 49, "label": "1", "ru": ["1","5","9"], "en": ["1","5","9"]}
        ]
      ],
      "macros": [
        {
          "name": "Отменить (Z+X → Ctrl+Z)",
          "chord": [90, 88],
          "send": [
            {"vk": 162, "up": false},
            {"vk": 90,  "up": false},
            {"vk": 90,  "up": true},
            {"vk": 162, "up": true}
          ]
        }
      ]
    }
  ]
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `activeLayout` | string | Имя активной раскладки из `layouts[].name` |
| `layouts[].name` | string | Уникальное имя раскладки |
| `layouts[].algorithm` | int | Алгоритм декодирования (2 — гибрид Trie+HMM) |
| `layouts[].keys` | array<array<key>> | Строки клавиш; каждая клавиша: |
| `key.vk` | int | Виртуальный код клавиши Windows (VK_*) |
| `key.label` | string | Подпись на кнопке |
| `key.ru` | string[] | Варианты символов для RU-раскладки |
| `key.en` | string[] | Варианты символов для EN-раскладки |
| `layouts[].macros[].name` | string | Имя макроса (chord) |
| `layouts[].macros[].chord` | int[] | Последовательность VK-кодов, запускающих макрос |
| `layouts[].macros[].send` | array<{vk:int, up:bool}> | Последовательность инъекций (SendInput) |

> **Примечание:** раскладка «Алфавит» — основная 4-кнопочная раскладка
> (бывшая опечатка «Алвафит» исправлена, см. code-style.md TD-6 ✅). Имя
> `name` должно совпадать с `activeLayout` при выборе.

### 2.2. `data/frequency_cache.json`

```json
{
  "прыжок": 1,
  "что-нибудь": 2
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| (ключ) | string | Слово (нижний регистр, RU или EN) |
| (значение) | int | Частота встречаемости (для ранжирования кандидатов) |

Загрузка: `json.Unmarshal` → `map[string]int`. Сохранение: `json.Marshal` → файл (0644).

### 2.3. `data/ngrams.json`

Сериализованная структура `МодельNграмм` (см. `статистика.go`):

```json
{
  "Цепочки": {"^": {"п": 1}, "^п": {"р": 1}},
  "Всего":   {"^": 1, "^п": 1},
  "РазмерN": 3
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `Цепочки` | map<string, map<string, int>> | Префикс → {следующая буква: частота} |
| `Всего` | map<string, int> | Префикс → общее число переходов |
| `РазмерN` | int | Порядок n-граммы (обычно 3 — триграмма) |

Маркеры начала/конца слова: `^` (начало) и `$` (конец), добавляются при обучении
(`"^" + слово + "$"`). Backoff: при отсутствии префикса берётся суффикс длины N-1.

### 2.4. Словари (`data/dictionaries/*.txt`)

```
слово1
слово2
...
```

- Один токен на строку, строчные буквы.
- Используются для построения `Трие` (метод `ДобавитьСлово`).
- `clean.py` — скрипт очистки/подготовки словарей (Python, утилита, не часть билда Go).

### 2.5. `data/user_words.txt`

То же, что словари, но пополняется в рантайме пользователем. Пуст по умолчанию.

## 3. Правила работы с данными

```yaml
правила:
  - "Все JSON-файлы сериализуются через encoding/json (без сторонних библиотек)"
  - "Права файла при записи: 0644"
  - "МодельNграмм и Трие загружаются в память при старте (см. поток.go)"
  - "При ошибке загрузки данных — СтатусОтвета с кодом ОшибкаЗагрузкиДанных + ВыводОшибки()"
  - "Частотный кэш обновляется в рантайме и сохраняется при выходе"
  - "Не менять формат ngrams.json без миграции (ломает обученную модель)"
```
