# Стиль кода проекта «Поток»

Обязательный стандарт для проекта `aoanima.ru/potok`. Наследует универсальный
шаблон `Templates/code-style.md` (уровень 0). Проект **уже следует** базовому
стилю (русские имена, `СтатусОтвета`, `Logger`, маркеры `AiCopilot-Code`).
Ниже — проектные уточнения и зафиксированные отклонения (tech-debt).

> Нарушение стиля — основание для отклонения на ревью (AC-POTOK-BASE-4).

---

## 1. Язык и именование

Наследует `Templates/code-style.md` §1. Проектные правила:

```yaml
принципы:
  язык: "ru"
  именование:
    функции: "ИмяФункции"            # Паскаль
    переменные: "имяПеременной"      # горбатый, без сокращений
    структуры: "ИмяСтруктуры"
    файлы: "русскоеСлово.go"         # поток.go, деревоСлов.go, статистика.go
  разрешено_как_есть:
    - "Имена Win32-структур и констант: INPUT, KEYBDINPUT, WH_KEYBOARD_LL, HWND, POINT"
    - "Тип ВиртуальныйКод (обёртка над VK-кодом клавиши)"
  запрещено:
    - "Сокращения (мк, спв, обр)"
    - "Транслит"
    - "Смешение языков в одном имени"
```

### Правильно / неправильно

```go
// ✅ Правильно
func ПолучитьПозициюКурсора() (Точка, СтатусОтвета) { ... }
var БуферНажатий []ВиртуальныйКод

// ❌ Неправильно
func getCaret() (POINT, error) { ... }   // латиница + error
var мк []ВиртуальныйКод                   // сокращение
```

## 2. Обработка ошибок

Наследует `Templates/code-style.md` §2. Используется `СтатусОтвета` из
`aoanima.ru/QErrors`. В проекте уже применяется:

```go
// ✅ Как в поток.go
статусЗагрузкиКэша := ЗагрузитьКэш(путь)
if статусЗагрузкиКэша.Код != QErrors.Ок {
    ВыводОшибки("не удалось загрузить кэш: %v", статусЗагрузкиКэша.Текст)
    return статусЗагрузкиКэша
}
```

Дополнительные коды Потока (реестр, см. `api-contract.md` §«Коды ошибок»):
`ОшибкаЗагрузкиРаскладки`, `ОшибкаУстановкиХука`, `ОшибкаПредсказания`.

## 4. Логирование

Наследует `Templates/code-style.md` §4. Библиотека `aoanima.ru/Logger`
(dot-import `. "aoanima.ru/Logger"`):

```go
// ✅ Правильно
Инфо("хук установлен, поток %d", идПотока)
ВыводОшибки("ошибка хука: %v", ошибка)

// ❌ Неправильно
log.Println("hook set")        // нативный log, латиница
fmt.Println("ошибка:", ошибка) // stdout вместо логгера
```

> **Отклонение (tech-debt):** в `поток.go` встречается `log.Println(...)`
> (примерно строки 549, 603). Требуется заменить на `Инфо()`/`ВыводОшибки()`.
> См. раздел «Известные отклонения».

## 5. Комментарии

Наследует `Templates/code-style.md` §5. Комментарии на русском, поясняют
**почему**. Запрещён закомментированный мёртвый код.

> **Отклонение (tech-debt):** файл `grid.go` содержит большие блоки
> закомментированного кода (layout-Grid JSON, `ПрисоединитьПотоки`,
> `ПолучитьАктивноеОкноИКаретку`, `GetCaretPosSys`). Требуется удалить или
> перенести в заметки. См. раздел «Известные отклонения».

## 6. Формат коммитов

```bash
git commit -m "Префикс(область): Краткое описание на русском"
```

| Префикс | Значение |
|---------|----------|
| feat | Новая функциональность |
| fix | Исправление ошибки |
| docs | Документация |
| refactor | Рефакторинг |
| test | Тесты |
| chore | Обслуживание |
| perf | Оптимизация |
| deps | Зависимости |

Области: `hook`, `predict`, `data`, `ui`, `config`, `build`.

```bash
git commit -m "feat(predict): добавлено Viterbi-декодирование для RU/EN"
git commit -m "fix(hook): утечка при снятии хука клавиатуры"
```

AI-агент делает коммит **после каждого логически завершённого изменения**.
