# Контракт интерфейса проекта «Поток»

> Наследует: `base-contract.md` (уровень 2)
> Переопределяет: `base-contract.md` §6 (нет REST API — интерфейс иной природы)
>
> Поток — **локальное Windows-приложение**, не веб-сервис. «API» здесь —
> это интерфейс взаимодействия компонентов: системный хук клавиатуры,
> внутренние каналы (Go channels) и инъекция предсказания через `SendInput`.

---

## 1. Входной интерфейс — системный хук

```yaml
хук_клавиатуры:
  механизм: "user32.SetWindowsHookExW(WH_KEYBOARD_LL, ...)"
  тип_события: "KBDLLHOOKSTRUCT { vkCode, scanCode, flags, time, dwExtraInfo }"
  обработчик: "ХукКлавиатуры (callback в поток.go)"
  действие: "Извлечение ВиртуальныйКод → добавление в БуферНажатий"

хук_мыши:
  механизм: "user32.SetWindowsHookExW(WH_MOUSE_LL, ...)"
  назначение: "Определение позиции курсора/каретки для размещения окна подсказок"
```

### Контракт виртуального кода

```go
type ВиртуальныйКод int   // обёртка над VK-кодом Windows (см. layout.json key.vk)
```

| Свойство | Требование |
|----------|-----------|
| Диапазон | Windows VK-коды (1..254), как в `layout.json` |
| Маппинг символов | Через активную раскладку `layout.json` (поля `ru`/`en`) |
| Автопереключение | Определяется язык (RU/EN) по набору допустимых символов для префикса |

## 2. Внутренний интерфейс — каналы (Go channels)

```yaml
каналы:
  каналПредсказания:
    тип: "chan []string"          # варианты слов, отсортированные по вероятности
    продюсер: "ПредсказаниеСлов (goroutine)"
    потребитель: "ПотокОбновленияЮИ"
  каналОбновленияОкна:
    тип: "chan struct{} / событийный"
    назначение: "Сигнал обновить ОкноПодсказок"
```

### Контракт предсказания (запрос → ответ)

Запрос (внутренний): буфер VK-кодов `БуферНажатий []ВиртуальныйКод`.

Ответ (схема из base-contract.md §8):

```json
{
  "варианты": ["привет", "приветствие", "притон"],
  "язык": "ru",
  "уверенность": 0.87
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `варианты` | string[] | Кандидаты, отсортированные по убыванию вероятности (лимит ~20) |
| `язык` | enum["ru","en","unknown"] | Определённый язык раскладки |
| `уверенность` | float[0..1] | Оценка достоверности лучшего кандидата |

## 3. Алгоритм предсказания (контракт поведения)

```yaml
пайплайн:
  шаг_1: "БуферНажатий → декодирование VK в множество символов (layout.json)"
  шаг_2: "Трие.ПоискСлова — все слова-кандидаты по префиксу (деревоСлов.go)"
  шаг_3: "МодельNграмм.Вероятность — оценка продолжения (статистика.go)"
  шаг_4: "Гибрид Trie + HMM, Viterbi-декодирование для выбора лучшего пути"
  шаг_5: "Ранжирование по частотному кэшу (frequency_cache.json)"
  шаг_6: "Отправка вариантов в каналПредсказания"
```

> Детальная спецификация алгоритма (при необходимости) — расширение
> `predict-contract.md` (см. base-contract.md §7).

## 4. Выходной интерфейс — инъекция и UI

```yaml
инъекция:
  механизм: "user32.SendInput (через syscall)"
  контракт: "При выборе кандидата — удаление набранного префикса + вставка слова"
  ограничение: "Только когда курсор в текстовом поле (по событию мыши/каретке)"

ui:
  библиотека: "github.com/rodrigocfd/windigo"
  компоненты:
    - "ГлавноеОкно — управление, настройки"

  обновление: "ПотокОбновленияЮИ читает каналПредсказания и перерисовывает окно"
```

## 6. Коды ошибок (реестр Потока)

Наследуют базовые из `QErrors` (см. base-contract.md §5.2). Дополнительные:

| Код | Значение | Когда |
|-----|----------|-------|
| `ОшибкаЗагрузкиРаскладки` | 5100 | Не удалось прочитать/распарсить `layout.json` |
| `ОшибкаУстановкиХука` | 5101 | `SetWindowsHookEx` вернул NULL |
| `ОшибкаПредсказания` | 5102 | Сбой в пайплайне предсказания (Trie/HMM) |
| `ОшибкаЗагрузкиДанных` | 5103 | Не удалось загрузить словарь/кэш/ngrams |

```go
const (
    ОшибкаЗагрузкиРаскладки = 5100
    ОшибкаУстановкиХука     = 5101
    ОшибкаПредсказания      = 5102
    ОшибкаЗагрузкиДанных    = 5103
)
```
