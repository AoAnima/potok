# Индекс контрактов проекта «Поток»

> Каталог системы контрактов. Точка входа — `base-contract.md`.

## Файлы

| Файл | Назначение | Статус |
|------|-----------|--------|
| [base-contract.md](base-contract.md) | Базовый контракт, метаданные, архитектура, принципы | ✅ готов |
| [code-style.md](code-style.md) | Стиль кода (русские имена, СтатусОтвета, Logger) + известные отклонения | 🔄 черновик |
| [data-contract.md](data-contract.md) | Локальные данные: словари, частотный кэш, n-граммы, раскладка, user-words | 🔄 черновик |
| [api-contract.md](api-contract.md) | Интерфейс: хук клавиатуры/мыши, каналы, формат предсказания | 🔄 черновик |

## Наследование

```
Templates/base-contract.md  (уровень 0, НЕ менять)
        │
        ▼
контракты/base-contract.md  (уровень 2, заполнен для Поток)
        ├── code-style.md
        ├── data-contract.md
        └── api-contract.md
```

## Не применимые контракты

| Контракт | Причина отсутствия |
|----------|-------------------|
| `role-contract.md` | Нет авторизации/RBAC — приложение локальное, без пользователей и прав доступа |
| `template-contract.md` | Нет веб-UI и шаблонизатора — интерфейс нативный Win32 (windigo), не HTML/Jet |

## Как использовать

1. Любое изменение в коде сверяется с `code-style.md` (обязательно).
2. Изменение формата данных (`data/`) — сначала править `data-contract.md`.
3. Изменение интерфейса хука/предсказания — править `api-contract.md`.
4. После правок запустить валидацию (см. base-contract.md §9).

## Валидация

```bash
# Из корня проекта
grep -rn '\{\{' контракты/ --include="*.md"   # не должно быть плейсхолдеров
grep -rn '| AC-' контракты/ --include="*.md" | sort | uniq -d   # не должно быть дублей AC-ID
```
